## 현재 화면 구조

1. **매수·매도 및 초기 비용**
   - 신규 주택 매수 희망가와 중앙푸르지오 매도가
   - 매수 − 매도 차액
   - 매도·매수 중개보수, 부가세, 인테리어비 납부 방식, 취득 시 필요경비
   - 세금을 제외한 초기 소요 비용
2. **세금**
   - 양도소득세, 취득세, 세금 합계
   - 실거주 시작일, 예상 매도·매수 잔금일
   - 전용 85㎡ 초과 여부와 매수 선행 시 일시자금 경고
3. **초기 자금 조달 + DSR**
   - 기존 주담대 전액 상환, 신규 주담대, 부모별 새마을금고 대출과 마이너스통장
   - 보험대출과 부모별 보유자산
   - 신규 대출 합계, 보유자산 합계, 초기 추가 필요자금
   - 부모별 현재 DSR과 생활안정자금 실행 후 예상 DSR
4. **생활안정자금 계획**
   - 세금과 선택한 카드 인테리어비의 5~12개월 카드 분할납부, 3개월 후 생활안정자금 1억 원 적용
   - 카드 잔액, 기간별 카드 납부액, 생활안정자금 실행 후 지속 월 원리금·이자
5. **전체 자금 요약**
   - 데스크톱 우측에 고정되는 핵심 결과 영역
   - 모바일에서는 본문 결과와 하단 고정 요약으로 제공
   - 상세 자금 내역은 기본적으로 접혀 있다.

과거의 별도 하단 `최종 납부 요약`은 현재 화면에서 숨겨져 있다. 우측 `전체 자금 요약`이 사용자가 보는 최종 결과이며, 숨겨진 `finalSummary`는 기존 렌더링 호환용 컨테이너다.

## 현재 요약 카테고리

우측 `전체 자금 요약`의 상세 내역은 다음 다섯 범주로 구성된다.

1. **매수 − 매도**: 매수 희망가, 매도가, 차액, 매도대금 순유입, 초기 소요 비용, 부족·여유 자금
2. **보유자산**: 아빠 자산, 엄마 자산, 보유자산 합계
3. **대출**: 신규 대출 합계, 생활안정자금, 생활안정자금 포함 총 대출금
4. **매월 나가는 금액**: 생활안정자금 실행 후 지속 원리금·이자, 1~3개월·4~카드 분할 납부 기간의 카드 납부액과 총 월 납부액, 카드 종료 후 월 납부액
5. **DSR**: 아빠와 엄마의 `현재 DSR + 생활안정자금 증가분`

요약 상단에는 초기 추가 필요자금 또는 여유자금을 가장 크게 표시하고, 신규 대출 합계·보유자산 합계·1~3개월 월 총 납부·4~카드 분할 납부 기간 월 총 납부를 바로 보여준다. 부족자금은 빨간색으로 표시한다.

## 대출 구조

### 아빠

- 새마을금고 대출
- 마이너스통장 한도
- 신규 주담대: 명의를 아빠로 선택한 경우

### 엄마

- 새마을금고 대출
- 마이너스통장 한도
- 신규 주담대: 명의를 엄마로 선택한 경우

보험대출은 부모별 명의를 구분하지 않으며 DSR에서 제외한다. 신규 주담대는 아빠 또는 엄마 한 명만 선택한다. 새마을금고 대출은 두 사람이 각각 받을 수 있다. 화면에는 모든 신규 차입의 **신규 대출 합계**가 별도로 표시된다. 3개월 후 생활안정자금 1억 원은 초기 신규 대출 합계에는 넣지 않고 별도 계획으로 표시한다.

## 보유자산 구조

### 아빠

- 현금
- 주식

### 엄마

- 현금성 자산(코인·현금 포함 전제)
- 주식

부모별 합계와 전체 **보유자산 합계**를 별도로 표시한다. 주식은 입력액 전액을 현금화할 수 있다고 가정하며 세금·수수료·가격 변동은 반영하지 않는다.

## 계산 로직 및 기준

### 매수·매도와 초기 필요자금

- 매도 중개보수 = 매도가 × 매도 복비율 × 부가세 계수
- 매수 중개보수 = 매수가 × 매수 복비율 × 부가세 계수
- 인테리어 납부 방식을 선택한다. 초기 비용 선택 시 인테리어비를 초기 소요 비용에, 카드 분할 선택 시 카드 원금에 포함한다.
- 초기 소요 비용 = 매수가 + 매도 중개보수 + 매수 중개보수 + 초기 비용으로 선택한 인테리어비
- 매도대금 순유입 = 매도가 − 매도 중개보수 − 기존 주담대 4.3억 원
- 신규 대출 합계 = 실제 반영 신규 주담대 + 부모별 새마을금고 대출 + 부모별 마이너스통장 한도 + 보험대출
- 초기 가용금액 = 매도대금 순유입 + 보유자산 합계 + 신규 대출 합계
- 초기 부족·여유 자금 = 초기 가용금액 − 초기 소요 비용

양도세와 취득세는 초기 소요 비용에서 제외하고 카드 분할납부 계획에서 별도로 다룬다. 인테리어 카드 분할을 선택한 경우에도 초기 소요 비용에서 제외하고 같은 카드 계획에 합산한다. 매수 잔금일이 매도 잔금일보다 빠르면 매도대금 유입 전 필요한 일시자금을 별도로 경고한다.

### 세금

- 중앙푸르지오 취득가는 17.1억 원, 취득일은 2022-12-20으로 고정한다.
- 양도차익 = 매도가 − 고정 취득가 − 매도 중개보수 − 취득 시 필요경비
- 1세대 1주택 고가주택 기준으로 12억 원 초과분을 안분한다.
- 장기보유특별공제는 완료된 보유연수와 거주연수에 각각 연 4%를 적용하고 각 10년까지만 반영한다. 3년 미만 보유는 공제하지 않는다.
- 과세표준에서 기본공제 250만 원을 차감한 뒤 누진세율을 적용하고 국세의 10%를 지방소득세로 더한다.
- 보유 2년 미만 또는 거주 2년 미만이면 현재 계산을 중단한다.
- 취득세는 전용 85㎡ 이하 3.3%, 초과 3.5%의 간이 추정이다.

주의: 세금 계산은 현재 구현 기준의 간이 추정이며 실제 요건과 최신 정책 검증이 필요하다.

### 신규 주담대와 DSR

- 실제 신규 주담대 = 희망액, 규제 한도, 차주별 DSR 한도 중 최솟값
- 규제 한도는 LTV 40%와 가격별 상한을 함께 적용한다.
  - 매수가 15억 원 이하: 최대 6억 원
  - 15억 원 초과 25억 원 이하: 최대 4억 원
  - 25억 원 초과: 최대 2억 원
- 부모의 연소득은 각각 1.5억 원으로 고정하며 기존 개인대출 연 원리금은 0원으로 가정한다.
- 신규 주담대는 원리금균등 상환액에 금리 유형별 스트레스 금리를 반영한다.
- 새마을금고는 약정금리에 1.5%p를 더한 원리금균등 상환액을 DSR에 반영한다.
- 마이너스통장은 실사용액이 아니라 약정 한도를 5년으로 나눈 금액과 약정금리+1.5%p 이자를 DSR에 반영한다.
- 생활안정자금은 현재 DSR에 포함하지 않고 선택한 차주의 증가분과 실행 후 DSR을 별도로 보여준다.

주의: 대출 가능액과 DSR은 현재 구현 기준의 시뮬레이션이며 금융기관 심사 결과가 아니다.

### 월 납부액

- 신규 주담대와 새마을금고 대출은 약정금리 기준 원리금균등 월 상환액을 사용한다.
- 마이너스통장은 입력한 한도 전액을 사용한다고 가정해 월 이자를 반영한다.
- 생활안정자금 실행 후에는 해당 대출의 월 원리금을 더한다.
- 사용자가 입력한 연간 보유세를 12개월로 나눠 월 납부액에 더한다.
- 보험대출은 금리와 만기 입력이 없어 월 납부액에서 제외한다.
- DSR용 스트레스 금리는 화면에 표시되는 실제 월 납부액에는 적용하지 않는다.

### 카드 분할납부와 생활안정자금

- 카드 원금 = 양도세 + 취득세 + 카드 분할을 선택한 인테리어비
- 카드 총 납부액 = 카드 원금 + 카드 수수료 추정액
- 5~12개월 중 선택한 기간에 균등 분할하며 처음 3개월의 월 카드 납부액을 계산한다.
- 3개월 후 남은 카드 잔액에 생활안정자금 1억 원을 우선 적용한다.
- 이후 남은 카드 잔액을 잔여 할부 개월 수로 나눠 4~선택한 카드 기간의 월 카드 납부액을 계산한다. 카드가 끝난 다음 달부터는 카드 납부액 없이 생활안정자금 실행 후 월 원리금·이자만 지속된다.

주의: 카드 납부 가능 여부, 실제 할부 수수료와 납부기한은 세목·카드사별 확인이 필요하다.

## 반드시 유지해야 하는 사항

- 기존 기본값과 계산식을 별도 요청 없이 변경하지 않는다.
- 금융 계산 로직 변경은 UI 개선과 분리해 명시적으로 검토한다.
- 아빠·엄마의 자산과 대출 구분을 유지한다.
- 새마을금고는 두 사람이 각각 입력할 수 있고, 신규 주담대는 한 명의 명의를 선택한다.
- 마이너스통장은 한도 전액을 사용액으로 가정한다.
- 신규 대출 합계와 보유자산 합계를 분리한다.
- `매수 − 매도`, `보유자산`, `대출`, `매월 나가는 금액`, `DSR`의 다섯 요약 범주를 유지한다.
- 세금을 제외한 초기 필요자금과 이후 세금 납부 계획을 구분한다.
- 기존 서비스 URL과 배포 경로를 유지한다.
- 숫자 입력, 슬라이더, 증감 버튼이 모두 같은 값을 갱신해야 한다.
- 모바일에서 가로 넘침 없이 핵심 결과를 확인할 수 있어야 한다.
- 네이버부동산 조회 기능과 버튼은 다시 추가하지 않는다.
- 외부 API·외부 스크립트 없이 브라우저 안에서 계산한다.

## 최근 변경사항

- 초기 자금 조달 영역의 대출을 아빠·엄마로 구분했다.
- 보유자산을 아빠·엄마로 구분했다.
- 신규 대출 합계와 보유자산 합계를 분리했다.
- 전체 자금 요약을 다섯 카테고리로 재구성했다.
- 현재 보이는 최종 결과를 우측 전체 자금 요약으로 통합했다.
- 마이너스통장 실사용액 입력을 제거하고 한도 전액 사용 가정으로 단순화했다.
- 인테리어비를 초기 비용 또는 카드 분할납부로 선택할 수 있게 했다.
- 카드 분할 기간을 5~12개월 선택 방식으로 바꾸고, 4~선택 기간 및 카드 종료 후 월 부담을 분리해 표시한다.
- 취득 시 필요경비와 매수·매도 잔금일 차이에 따른 일시자금 경고를 추가했다.
- 공개 서버의 계산 스크립트 CSP와 숫자 입력 가독성을 보완했다.
- 외부 AI 검토용 컨텍스트·변경 이력·버전 정보를 공개 배포에 추가했다.
- GitHub Raw 동기화 스크립트를 추가했다. 공개 저장소와 GitHub 인증을 연결하면 배포 후 문서를 자동 push한다.

## AI 검토 가이드

이 문서는 ChatGPT/Claude 등 외부 AI가 현재 계산기 상태를 빠르게 이해하기 위한 공개 문서다. 검토할 때 다음 관점을 우선 확인한다.

- 전체적인 시인성과 정보 위계
- 입력에서 결과 확인까지의 흐름
- 모바일 가독성
- 중복 정보와 불필요한 설명
- 핵심 자금 정보의 강조 수준
- 매수·매도, 자산, 대출, 월 부담, DSR 사이의 관계
- 일반 사용자가 계산 결과와 가정을 쉽게 이해할 수 있는지
- 부족자금과 실행 시기별 현금흐름이 분명한지

검토 단계에서는 코드를 직접 수정하기보다 개선안과 Codex용 작업지시를 작성한다. 세금·대출 정책이 맞는지 검토할 때는 이 문서의 값을 확정 규칙으로 간주하지 말고 최신 공공기관 자료와 실제 상품 조건을 별도로 확인한다.
